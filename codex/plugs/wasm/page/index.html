THE COMPILER BUILDS ITSELF

The Codex compiler, compiled to WebAssembly by its own wasm plug, running in this browser tab. Press the button and it compiles its complete source, every phase from tokenize to emit, then proves its output byte-identical to the same compiler running on bare metal.
Nothing is uploaded and nothing is compiled on a server. The page fetches two files, the compiler as a wasm module and the compiler's own source, and every step after that happens in this tab.

COBBLESTONE
Built with Codex.
Cobblestone is the path; Codex is the stone it is paved with. Codex is a self-sustaining language, compiler, and computational substrate.
The module imports two WASI calls, fd_read and fd_write, shimmed above in a few lines of JavaScript. No server round-trips: the build happens entirely in this tab.
The build is tried on a worker thread first and retried on the main thread when the worker's stack is too small for the emit spine, so whichever one finishes is itself the measurement.
