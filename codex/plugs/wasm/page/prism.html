    What runs here, and what does not.
    The compiler emits the intermediate representation itself, so that runs in this
    tab directly. Every other target is a separate program, a plug, that reads
    the IR and writes the target; a plug lights up here once it is compiled to
    WebAssembly the same way the compiler was. JavaScript and C# are done, and the IR
    on the first pill is exactly what they consume.
    The binary formats are not wired yet: ELF, PE and a disk image come from
    plugs that emit bytes rather than text, which needs one more entry point on the
    plug side before this page can hand you a file. When it lands, choosing one here
    downloads it.
