    What runs here, and what does not.
    The compiler emits the intermediate representation itself, so that runs in this
    tab directly. Every other target is a separate program, a plug, that reads
    the IR and writes the target; a plug lights up here once it is compiled to
    WebAssembly the same way the compiler was. The IR on its own panel is exactly
    what every one of them consumes.
    The UI tab is the same compiler pointed at interfaces: the HTML lens emits
    a whole document, and Render the page puts it in a sandboxed frame so the
    box model you described in Codex is the box model the browser lays out.
    The Binary tab hands you a file. Those plugs read a compiled payload
    rather than the IR, so the compiler runs again in CDX mode and the CDX goes to
    the PE plug, and to the disk-image plug after it: what comes back is a bootable
    EFI binary or an 8 MB GPT image, built in this tab and saved by your own
    browser. The targets are grouped by what you end up with. Boots a
    machine is four ways to package the same program: the CDX itself, a
    bootable ELF for qemu -kernel, a UEFI application that firmware
    loads off an EFI partition, and a whole 8 MB disk with that application
    already on it, which is the one to write to a stick. Runs on an OS is
    two programs you can hand to somebody: a Linux app and a Windows
    .exe. Both are the same compile with a different floor under
    it -- the runtime cells move off the addresses each system reserves,
    printing leaves through write(2) or WriteFile, and
    the entry stops building page tables it does not own. Both were graded
    against the same expected-output files the bare-metal battery uses, so what
    they print is what the kernel prints, byte for byte. The Linux one was
    measured on WSL2; that it runs on any x86-64 Linux is an assertion resting
    on the artifact having no host surface -- no interpreter, no libc, two
    syscalls. The Windows one has ASLR off because the code is patched for one
    address, and it has been run on one machine.
