# build/test-compile-baseline.txt
#
# Test chapters that CANNOT compile standalone, and are not defects.
#
# build/check-test-compile.ps1 compiles chapters under codex/test with a plain
# compile.ps1 and no harness. A chapter whose own runner supplies an input the
# compiler needs will answer an error to that, correctly, forever. Naming it
# here is what keeps the check from crying wolf; red's ruling 2026-08-20 is that
# a check which cries wolf gets ignored and is then worse than nothing.
#
# This file is NOT for a chapter that is merely broken. A broken chapter is a
# red and gets fixed. Add a line here only when the chapter compiles under its
# own runner and cannot compile without it, and say which runner.
#
# Chapters carrying a .failing sidecar are excluded by the check itself and do
# not belong here either.
#
# One relative path per line, then two spaces, then the reason.

codex/test/quote-from-peer.codex   CDX3020: the quotation resolves from a live peer. build/quote-from-peer-test.ps1 stands one up and compiles this with -Peer 127.0.0.1:<port>.
codex/test/quote-from-store.codex  CDX3020: the quotation resolves from an attached store. build/test-quote-from-store.ps1 supplies it.
