# compiler-order.txt -- the order codex/compiler is concatenated in.
#
# concat-codex-self.ps1 reads this file and refuses any disagreement with the
# directory: a .codex under codex/compiler that has no row here, or a row here
# with no file. Add a row when you add a file; the refusal names which.
#
# WHY THE ORDER IS EXPLICIT. It used to be derived from FILENAMES: an ordinal
# sort per directory, then a hoist of any file whose NAME matched State|Encoder
# to the front of its quire. That hoist was a dependency fact rather than a
# preference, so the build depended on what files were CALLED, and renaming a
# file silently reordered the unit the compiler is built from. The four
# multi-file chapters are why cites cannot supply the order instead: the
# hoisted files are in the SAME chapter as the files that need them, and a
# cite is between chapters, so no cite graph can express their order.
#
# Rows are repo-relative, one per file, in concatenation order. Blank lines and
# # comments are ignored.
