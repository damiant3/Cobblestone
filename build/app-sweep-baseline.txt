# App sweep baseline -- the entry units known NOT to compile, and why.
#
# The apps are the extended pin on the compiler: 265 diverse programs
# exercising the front end. A unit that stops compiling is a compiler or
# foreword regression until proven otherwise, which is what
#   pwsh build/sweep-app-classes.ps1 -Check -Jobs 3
# fails on. Anything dirty and not listed here is a regression.
#
# Every unit below fails on names that do not exist and never did. That
# is application work -- a missing API or an undesigned vocabulary -- not
# drift under the compiler, so these are deliberately left. Do not add a
# unit here to make the pin green: if it broke, it broke.
#
# Do not record a clean count or a seed digest here. Both move, and a
# number in this file would be one more thing to carry forward wrongly.
# The check compares against this list, not against a remembered total.

apps\games\codexmagic\SimBaseline.codex    apply-screw-fix / apply-flood-fix do not exist. Must NOT be stubbed: SimBaseline defines rules-screw, rules-flood and rules-screw-flood specifically to A/B these mechanics, so an identity stub makes the simulator report that the fix has no effect -- a confident wrong answer from the one tool whose job is measuring that effect. Semantics live in GameRules and design/History/Mana.md.
apps\games\codexmagic\SimRunner.codex      Same two names as SimBaseline.
apps\explorer\CardEmitDemo.codex           CardEmitter mana-cost-* against two incompatible card models. The cite swap is a recorded trap; do not retry it without resolving which model wins.
apps\explorer\ExcaliburSlice.codex         Same CardEmitter mismatch as CardEmitDemo.
apps\fontai\FontExtract.codex              Wants a raw-byte read from serial and no builtin exposes one. read-serial-cce returns CCE, which would corrupt a TTF at the I/O boundary. Needs a primitive decision, not an app fix.
