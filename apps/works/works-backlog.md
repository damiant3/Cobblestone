# Works -- open capabilities

App-domain backlog. There is no platform-wide register any more:
`docs/PM/BACKLOG.md` was deleted 2026-07-23 and must not be recreated.
`docs/PM/CurrentPlan.md` carries the shape and the priority order for
the platform. Anything that is this application's own behaviour lives
here.

The rules are the same ones: an entry says what is still missing and
nothing else, a closed entry is DELETED rather than annotated, and a
gap that is still real is never quietly dropped.

**`works-desk-contract.md` is the standing rules for the desk** -- the `ds`
cell map and the rule about pointers in it, the base heap mark and how a pane
exits, the cursor bracket, why the palette arrives as a parameter. Read it
before adding a pane or taking a cell. This file is what is missing; that one
is what must not be broken.

## Standing check: every chapter must compile on its own cites

```powershell
build/check-subset-cites.ps1 -Root apps\works -Jobs 8 -Kernel seed\Codex.cdx
```

**Run it after any cite change and after adding a chapter.** It builds each
chapter as its own unit -- the chapter plus the transitive closure of what it
cites -- and lets the compiler answer, so a chapter using a name it never cited
is caught here instead of by whoever next assembles a subset. That is L-SUBSET,
and the glob build cannot see it.

**Clean 2026-08-19 (val), 111 chapters, and it was not clean when first
pointed here.** Nobody had ever aimed it at this quire; the first sweep found
`GopConsole` borrowing `gfl-is-dir` and `gfl-pad` from `GopFiles` and
`rtc-seconds` from `GopRtc`, all three uncited (fixed, main 17536), on the back
of `GopScene` borrowing `mouse-x`/`mouse-y` from `GopUsbMouse` the same day
(main 17513). Both were invisible to the desk build, which reaches those
chapters through `GopDesk`'s cites.

**112 of 112 compile, and `DeskBoot` is FIXED (red, main 17598; re-measured
here 2026-08-19 after the merge that carried it).** It had stopped at CDX2031:
`db-flow` declared `[Device.Port, Device.Mmio, Gpu.Compute, Gpu.Memory]` and
WORKS-44 stage 2 had put `Identity` in the desk's effect rows, missing this one
entry chapter. What located it was the count rather than the error text --
`GopDesk` carried `Identity` on 33 signatures and `DeskVm` on 1, both updated
with that work, and `DeskBoot` on none. Kept here because the shape recurs: an
effect added across a desk has to reach EVERY entry point, and only a
standalone build ever notices the one it missed.

**And the verdict line still cannot say so.** `check-subset-cites.ps1` counts a
failing unit into `$failed` but only ever PRINTS a chapter name for a
`CDX3002`/`CDX2002` undefined-name error; a unit that fails for any other
reason is reported as a bare count and never named, and the run still ends
`OK`. Finding `DeskBoot` took a re-run with `-KeepUnits` and a grep of the
logs. The script is red's; the one-line repair is to print `$failed` whenever
it is non-empty.

**Coverage is 111 of 111, and read that line rather than the verdict.** For a
few hours on 2026-08-19 it was 104 of 111: the seven entry-point chapters
(`BlockLadderProbe`, `DeskBoot`, `DeskVm`, `GopBoot`, `SdExplorer`,
`SinkLadderProbe`, `UefiBoot`) all failed `CDX3001: 'opening' is defined in
multiple chapters`, because the harness appended a trivial entry point of its
own and those chapters already had one -- so they were never examined for
borrowed names while the run still printed OK. red closed it the same day; a
chapter that defines `opening` now keeps its own. **And NOTHING sweeps docs/Probes at all**, so a probe is the unit that rots most quietly: `annotation-mark.codex` stopped compiling the moment its subject's `ged-annots-load` gained an effect, and only an unrelated build a day later noticed (val, 2026-08-19). A probe is source that cites live chapters; when you change a signature, grep `docs/Probes` as well as the tree.

**The habit outlives the
defect: a unit that does not compile is a chapter that was not judged, and the
verdict line does not say so.**
