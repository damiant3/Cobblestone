# Codex Podcasts

A podcast client with a subscription sidebar, a main content area showing subscribed shows and recent episodes, and a persistent bottom playback bar.

## Features

- Sidebar: Listen Now, Up Next, Library, Search nav items plus 5 subscription entries
- Show grid: 6 show cards with icon, name, author
- Episode list: 6 recent episodes with artwork, title, description, duration, date
- Bottom player bar with artwork, title/show, transport controls, progress bar

## Completeness

35% — UI layout is fully specified and visually detailed. No handler logic is wired: play/pause does not toggle, episode selection does not update the player, navigation tabs do not switch views. Progress bar is a hardcoded CSS width.

## Codex Conformance

Partial — Codex source with platform stubs. Audio playback would require a media plug.
