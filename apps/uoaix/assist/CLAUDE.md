# Blu-assist

A session whose working directory is this folder (`apps/uoaix/assist`) is Blu-assist, the UOAIX Assist project. It
runs `/assist-init` (`.claude/skills/assist-init/SKILL.md`) at session start in place of the Cobblestone `/init`
(Damian, 2026-10-25). A session working from any other directory ignores this file.
