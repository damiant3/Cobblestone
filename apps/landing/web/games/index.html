The Arcade

Pick a game. Every one of them is a Codex engine compiled to WebAssembly by the project's own backend, running in this tab. No server decides anything, and no JavaScript plays a move.

Open the full page →
Choose a game from the list.

What is running here. Each game's rules live in apps/games/classic/<Game>.codex. apps/games/build-wasm.ps1 compiles that to the compiler's inner language, hands it to codex/plugs/wasm, and the module your browser loaded is what came back.

The opponents are the engines' own. Where a game lets you take a turn, your click goes to the module's legality test first and is refused if the rules refuse it.
