The Royal Game of Ur

Circa 2600 BCE, and the oldest set of rules we can still play. Race seven pieces along fourteen steps and bear them off. Four binary dice give you 0 to 4; a rosette grants another turn, and landing on an enemy piece in the shared lane sends it home. The engine is Codex, the same source the bare-metal build runs, compiled to WebAssembly by the project's own wasm backend.

What is running here. apps/games/classic/RoyalUr.codex holds the rules and the AI. apps/games/build-wasm.ps1 compiles it to the compiler's inner language, hands that to codex/plugs/wasm, and the module your browser just loaded is what came back. No JavaScript decides a move, and no JavaScript knows a rule: even whether a piece may move is ur_can, answered by the engine.

The page holds a handle, not a board. Tic-Tac-Toe fits its whole game in one integer, so that page carries the state itself. Ur needs about 71 bits and cannot, so the module answers an address and the page hands it back. That is why this page resets the module heap when a game starts and never between moves, where Tic-Tac-Toe resets before every call.

How it is graded. Dice mean there is no exhaustive answer key to check against, so apps/games/ur-verify.mjs asserts the rules instead: every reachable position keeps its pieces in range, forty games run to a finish with the winner bearing off exactly seven, and ur_can is made to agree with the engine's own refusal on every piece and roll of a whole game.
