A relational database, answering in this tab

Codex DB is a real relational engine written in Codex: a catalog, typed rows, a query executor, and a relational algebra of scans, filters, projections, sorts, limits, joins and grouped aggregates. Here it is compiled to WebAssembly. Pick a query and you get two things: the algebra that was executed, and the rows it returned. Nothing is precomputed and no server is involved.

There is no SQL here, and the page is not hiding one: this application has no
  SQL parser, so what it offers is the algebra underneath SQL, selected by name. The engine also
  carries a write-ahead log, MVCC, a lock manager and two-phase commit, none of which this page
  exercises. Each query runs a fresh instance of the module against a freshly seeded catalog.
