A computer algebra system, in this tab

Type an expression. It is parsed, simplified and printed by a symbolic algebra engine written in Codex and compiled to WebAssembly by the project's own backend. It keeps exact rationals rather than falling back to floating point, and it collects like terms instead of just doing arithmetic.

Each evaluation runs a fresh instance of the module: the expression goes in on standard input and the answer comes back on standard output, which is how the compiler's own page works. That means there is no collector to worry about and no state carried between lines, so x := 3 will not be remembered by the next expression yet.
