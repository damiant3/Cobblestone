Safari

A driving screensaver, ported to Codex by Steve Howell and compiled to WebAssembly by this project's own backend. Every polygon below was decided by Codex running in your browser: the page only paints what the module hands it.

loading the module ...

The module exports sfw_render(step), which walks the ride to that step, renders one frame and writes the draw commands into its own linear memory, and sfw_buffer_at(), which says where. This page decodes that buffer and paints it. It makes no decision about what is worth drawing: port/Blit.codex already did, which is why the module runs blit-expand before it writes. The painting recipes here follow Steve's blitter.js, which is his fork of the original game's, and the source is at github.com/showell/safari-codex.
