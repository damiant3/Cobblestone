Compiled in this tab, then run in this tab experimental

Everything else on this site ships modules that were built on our box and copied up. This page skips that: it fetches the Codex source of a demo, compiles it with the Codex compiler running as WebAssembly, hands the result to a backend that is itself Codex compiled to WebAssembly, and runs what comes out. Nothing is sent anywhere. The question it exists to answer is whether the site can stop shipping built artifacts and build them where they are viewed.

A GPU kernel, compiled live and drawn

The plasma demo from the GPU showcase: apps/gpushow/kernels/PlasmaKernel.codex and the one library chapter it cites are fetched, compiled to the compiler's IR by codex-compiler.wasm, lowered to WGSL by wgsl-stdio.wasm (the WGSL plug as a WebAssembly module), checked against the shader the showcase ships, and then dispatched to your GPU. Needs WebGPU, which today means a recent Chrome or Edge.

1. fetchsource and library chapter
2. compileCodex → IR, in wasm
3. lowerIR → WGSL, in wasm
4. compareagainst the shipped .wgsl
5. runWebGPU compute, one thread per pixel
