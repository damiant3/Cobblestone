A Commodore 64, in this tab

A 6502, the VIC-II, the CIAs and the real BASIC, KERNAL and character ROMs, written in Codex and compiled to WebAssembly by the project's own backend. Nothing here is JavaScript but the keyboard and the canvas blit: the CPU runs, the screen is drawn, and the READY prompt you see is the actual KERNAL booting. Click the screen and type.

Type PRINT 2+2 and press Return. BASIC is the real thing, so 10 PRINT "HI" / 20 GOTO 10 / RUN works too. The emulator's whole machine -- 64 KB of RAM, the ROMs, the colour RAM, the VIC and CIA registers -- lives at fixed addresses in the module's linear memory, which is why it keeps running between frames without the page holding any state at all.
