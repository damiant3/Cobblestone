# Codex Calendar

A calendar application with sidebar mini-calendar, multi-calendar folder list, and a main area that switches between Month, Week, Day, and Agenda views.

## Features

- Four view modes fully implemented as widget trees: month grid, week time-grid, day time-column, and agenda list
- `days-in-month` and `month-name` date helpers with leap-year calculation
- Working mini-calendar with today highlighted and four calendar folders with dot indicators
- Multi-color event categorization (blue/green/orange/red/purple)
- View-switch buttons wired and functional

## Completeness

55% — All four views render with plausible sample data and view-switching is live. Mini-calendar and folder list are complete. Date navigation (prev/next/today) declared but not implemented (month hardcoded as June 2026). Event creation, folder toggling, and event detail drill-down are absent. All event data is hardcoded.

## Codex Conformance

Full — Pure Codex throughout. Theme, CSS, and widget tree follow the established foreword pattern.
