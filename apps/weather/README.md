# Codex Weather

A weather dashboard for a single location showing current conditions, hourly forecast, 7-day forecast, and atmospheric detail cards.

## Features

- Current conditions: emoji icon, temperature, feels-like/high/low/humidity/wind/UV/visibility
- Hourly forecast: 10 hour-cards with time, icon, and temperature
- 7-day forecast: grid of day-cards with day name, icon, high, and low
- Atmospheric detail cards: UV Index, Wind, Humidity, Visibility, Pressure, Sunrise/Sunset
- Night-sky gradient background

## Completeness

30% — Display structure is complete and visually polished. All data is hardcoded static (Portland, Oregon). No location search, no unit toggle, no live data fetch, no state-driven updates.

## Codex Conformance

Full — Written in Codex with platform stubs. No interactivity means no stubs are left unimplemented. Live data would require a network plug.
