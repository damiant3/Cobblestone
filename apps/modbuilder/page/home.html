Get started

Explore now. Connect your game when ready.

Open the downloaded workspace directly from disk. No website server is required. Projects save in browser storage; export a ZIP to keep a portable copy, or use Open folder to edit files on disk.

Review the helper source, compile in your browser, choose Save EXE as, then open ModBuilder.exe and allow setup. The native helper finds Valheim through Steam and opens your connected workspace. No Git checkout, Visual Studio or SDK is needed for setup.

Completed steps collapse into cards: setup, choose features, compile project, build, deploy and launch. The uninstaller follows the same source, compile and save flow. The helper changes only its own local settings.

Native preview: discovery and connection are ready. Direct playable-mod binaries, testing and installation remain in development. The existing developer bridge still supports mod builds with a checkout and Windows build tools.
