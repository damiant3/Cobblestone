Spark

A software 3D renderer written in Codex, compiled to WebAssembly, drawing into a framebuffer your browser blits to a canvas.

loading the module ...

Every pixel above is computed by Codex. apps/spark/SparkWasm.codex builds the scene, and SceneRender rasterises it into a Framebuf, which SparkDisplay blits to a display. On bare metal that display is the GOP framebuffer at 0x40000000; here it is a region of WebAssembly linear memory, and the only difference is the address the display record carries.

The JavaScript on this page does not draw. It instantiates the module, calls spark_render once, and copies the framebuffer onto the canvas.
