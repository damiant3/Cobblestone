Codex GPU Showcase

WebGPU compute demos whose shaders are generated from Codex source.

Every compute shader on this page is written in Codex as a [Device]-effected kernel, then compiled to WGSL by a self-hosted transpiler plug (codex/plugs/wgsl) and run in the browser via WebGPU. No hand-written shader logic in the compute pass -- it is lowered from the same typed AST the Codex compiler uses. Hit </> Source on any card to read the Codex that generated it.
kernel.codex --[compile -IrCce]--> IR --[wgsl-plug]--> kernel.wgsl --[WebGPU]--> pixels
