How to Play 2048

Goal: Slide and merge tiles to create a 2048 tile (or higher).

Play: Each turn, all tiles slide in one direction. When two tiles of the same value collide, they merge into one tile with double the value.

Spawning: After each move, a new tile (2 or 4) appears in a random empty cell.

End: The game ends when no more moves are possible (board full, no adjacent matches).

This simulation: AI picks the best direction each move using a heuristic strategy.
