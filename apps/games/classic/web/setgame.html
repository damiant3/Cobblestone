How to Play Set

Goal: Find all valid sets among the cards on the table.

Cards: Each card has 4 attributes: Number (1/2/3), Shape (diamond/oval/squiggle), Color (red/green/purple), and Shading (empty/striped/solid).

Valid set: 3 cards where, for each of the 4 attributes, the values are either ALL the same or ALL different across the 3 cards.

Example: 1-red-solid-diamond + 2-green-striped-oval + 3-purple-empty-squiggle is a valid set (all attributes are all-different).

This simulation: AI finds sets automatically. When a set is found, those 3 cards are replaced from the deck.
