# Codex News

An RSS/news-feed reader with a two-column layout: a categorized sidebar and a main content pane switching between article list and single-article reading view.

## Features

- Sidebar with three feed groups: Favorites, Categories (Technology, Science, World, Business, Health, Sports), Sources (Reuters, AP, Ars Technica, Nature)
- Unread-count badges on category items
- Article list with source, timestamp, title, excerpt, and emoji thumbnail
- Reading view with back-navigation, source attribution, date/read-time, and multi-paragraph body

## Completeness

45% -- UI structure and navigation skeleton are complete. Article data is hardcoded static; reading view always shows the same article regardless of which row was clicked. No feed-fetching, no RSS parsing, no saved/recent persistence, no search.

## Codex Conformance

Partial -- Written in Codex with platform stubs. No backend or client plug wired yet.
