# Codex Fitness

A fitness tracking dashboard displaying three Apple Watch-style activity rings, daily stats, a weekly bar chart, quick-log workout shortcuts, and a recent workout history list.

## Features

- Three concentric-ring components (Move/Exercise/Stand) with CSS conic-gradient arcs
- Four stat cards (Calories, Exercise, Steps, Distance)
- Quick-log section with 8 workout-type buttons
- Weekly bar chart (Mon-Sun) with calorie values
- Seven recent workout items with type, metadata, and calorie burn

## Completeness

45% — Display is rich and visually complete for a read-only dashboard. No interaction is implemented: quick-log buttons don't open a logging modal, workout items aren't selectable, bar heights not driven by the percentage parameter. Date header is hardcoded.

## Codex Conformance

Full — Written in Codex using Widget/Theme foreword primitives and local stubs.
