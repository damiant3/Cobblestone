# Codex Markets

A financial data dashboard covering stocks, bonds, commodities, and a personal watchlist, with sidebar index trackers, a scrollable ticker strip, and a market news feed.

## Features

- Four full tab views: Stocks (ticker strip, chart placeholder, 10-row stock table, news), Bonds (Treasury yield cards, yield curve, corporate/municipal tables), Commodities (Precious Metals, Energy, Agriculture, Industrial Metals), Watchlist (8-symbol table with Add Symbol)
- Sidebar with Markets/Personal nav groups and Indices section (S&P 500, Dow, Nasdaq, Russell 2000)
- Ticker strip with 7 tech stocks showing up/down coloring
- Period buttons (1D/5D/1M/3M/6M/1Y/5Y/Max)

## Completeness

60% -- All four views render with substantial realistic data and tab navigation is fully functional. Charts are placeholders. Period buttons, Add Symbol, Portfolio, and Alerts do nothing. All prices are static. No live data feed.

## Codex Conformance

Full -- Written entirely in Codex. Market data feed integration is a backend plug responsibility.
