# Codex Recorder

A voice recorder with a record/stop control, an animated waveform display, a timer, and a library of past recordings.

## Features

- Central display: timer label, 20-bar waveform, RECORDING/READY status
- Controls: discard, record/stop toggle, done
- Recordings library with 4 items (name, date, duration)

## Completeness

35% — Recording state toggle (RECORDING vs READY) is functional. Timer does not advance. Waveform bars do not animate. No audio capture. Library items are static. Play buttons do nothing.

## Codex Conformance

Partial — Codex source; microphone capture and audio playback require platform plugs.
