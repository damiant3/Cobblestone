# reek -- workplan

*Empty by design. Keep it that way.*

This file holds ONE session's in-flight lane state and nothing else: what is
shelved, what is mid-gate, what the next action is. It is emptied at handoff,
not appended to.

Open work does not go here. Cross-lane items go to `docs/PM/CurrentPlan.md`;
an item originating in one app or quire goes to that register; a durable fact
goes to the doc that owns the subject.

A list of pointers to those homes does not belong here either. It is a second
index that drifts against the first, and it is what this file was carrying
until 2026-08-17.
