# LinkedIn post draft

Vikings, vegetables, and a compiler in your browser. Now we're having fun. ⚒️🌱

I've been building Cobblestone ModBuilder: a little workshop for making Valheim feel more like YOUR Valheim.

Want to plant neat rows instead of spending the evening clicking carrots into the ground? Give the hoe a new job? Tidy up the health and food display? Link storage around a workbench? Give the local neck population a chance to stay cleared?

Pick your features. Combine a pack. Change the code if you're feeling adventurous. Then compile, deploy, and get back to the game. 🎮

The compiler runs locally in your browser. No Git checkout, Visual Studio installation, or whole development environment required. The workspace even works as a standalone HTML file.

And here's the part I care about: build locally, with the source in front of you. 🔎

Review and compile the helper yourself, save the EXE, and choose when to run the helper. Build your mod DLL in the browser, then use the helper to deploy into a separate Valheim play copy. Deployment backs up the previous mod loader and shows where the new build went.

Local compilation adds visibility and control. Source review and save backups still matter; compiling code yourself doesn't automatically make the code safe.

The build identifier on the page matches the identifier in the game. A small detail, but a lovely way to answer, “Am I actually running the version I just built?” 😄

Early days, plenty more to explore, and already a very enjoyable excuse to mix language tools with Viking gardening.
