# GitHub Update 73

Covers main 49090 through 53217. Time zones are built end to end: tzdata 2026f is vendored, all 345 zones compile identical to zic's TZif through 2037, 92548 local-time probes match Python zoneinfo, and the desk clock, first-boot wizard, scheduler and X.509 clock run on a zone. The TLS 1.3 and DTLS 1.3 endpoints are hardened against out-of-rule input across dozens of checks, and their heap falls sharply (a 200,000-byte TLS send from 7,092,480 to 2,286,496 bytes, an X25519 call from 2,469,056 to 1,280 bytes, a TCP connection from 33,554,496 to 4,176 bytes of receive buffer). The ACCP lease, information-flow, decidable-policy, grant-prose and human-approval ladders advance through several rungs each. Effect handlers now run on the python, javascript, typescript, perl, csharp and zig plugs. Fat16, Fat32 and GPT readers refuse a long list of hostile layouts, and codex-vm refuses malformed kernels and guest addresses instead of faulting the host. A column-2 prose campaign and a history sweep clean the compiler, plugs, tests and apps, and the release gate stops running plug and cross phases. One follow-up to a GitHub issue from an outside contributor lands. Numbers in parentheses are main changelists.
